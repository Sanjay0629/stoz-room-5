My Second Blog Post

After learning the basics of HTML, I started learning CSS. CSS allows us to make HTML pages look attractive and professional.

Why CSS is Important

Without CSS, a webpage mainly contains plain content. CSS allows us to control colors, spacing, fonts, layouts and many other visual properties.

I practiced properties such as margin, padding, background-color, font-size and text-align.

What I Learned

  • CSS selectors
  • Colors and backgrounds
  • Margins and padding
  • Fonts and text styling
  • Basic page layouts

Conclusion

Learning CSS made it possible for me to turn a simple HTML page into a much better-looking website.
